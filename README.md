# Word to Canvas

> You can convert a Word document into a Canvas-compatible QTI .zip file by formatting your text, running it through an online quiz converter, and importing the package into your course. [1] 

## 1. Prepare Your Word Document

* Type your questions with auto-numbering or standard numbers (e.g., 1.).
* List choices with letters like a), b), or c).
* Mark the correct answer with an exclamation point (!) or an asterisk (*) depending on the specific converter tool you use.
* Save your final file as a .docx or plain text .txt file.

## 2. LSTS Word to Canvas Quiz Converter

* What it does: Built specifically to help educators instantly bridge the gap between Word and Canvas LMS.
* Key feature: Allows you to embed images, mathematical equations, and tables directly into your Word document, preserving them in the final QTI package.
* Link: Convert files using the [LSTS Utility Tool](https://utility.lsts.edu.vn/convert-quiz). 
* Upload your prepared file to the conversion tool.
* Check the preview or error validator for mistakes, then download the generated QTI .zip file.

## 3. Import Into Canvas

* Log in to Canvas and open your course.
* Go to Settings and click Import Course Content (or select Import Existing Content from the homepage).
* Choose QTI .zip file from the Content Type drop-down menu.
* Upload your downloaded .zip file and click Import.

## 3. NYIT / SDSU Canvas Exam Converters

* What it does: Classic, lightweight university text-to-QTI utilities (originally developed by San Diego State University and adapted by New York Institute of Technology). [5, 6] 
* Key feature: Works best if you save your Word document as a plain text (.txt) file first. You paste your text into a browser window, click convert, and receive the .zip. [5, 6] 
* Pro-tip: You can paste the NYIT formatting rules into an AI assistant, provide your raw test, and ask it to format the text perfectly before pasting it into the tool. [6]

* Key feature: Supports complex layouts, sub-questions, and open-ended text questions.

## ⚠️ Crucial Step After Importing to Canvas
When you upload the QTI .zip file into Canvas (Settings > Import Course Content > QTI .zip file), Canvas initially builds it as a Classic Quiz. [4, 6, 8] 
If your institution uses Canvas New Quizzes, locate the imported quiz on your "Quizzes" page, click the three vertical dots on the right, and select Migrate to update it to the modern format. [6]
